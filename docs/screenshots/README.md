# Marketing screenshots

All images in this directory are synthetic demo assets. They must not contain
real session transcripts, repository names, usernames, URLs, costs, prompts, or
company data. Keep the matching copies under `website/public/` synthetic too.

Before adding a screenshot, inspect it at full resolution and run OCR or a
manual redaction pass. Prefer generic labels such as `Sample replay` and
`demo-project` over data taken from a real coding session.
